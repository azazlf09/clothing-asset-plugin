# 服装资产库 · 反推助手 —— 使用教程

> 面向公司同事的第一次安装 & 日常使用指南。
> 看到好看的穿搭，一键存进资产库，并自动反推出服装提示词。

---

## 一、这个插件是什么

一个 Chrome 浏览器扩展，配一个本地后台小程序：

- **浏览器扩展**：负责界面（侧边栏、悬浮按钮、资产库），你在网页上看到好看的衣服，点一下就能保存 + 反推提示词。
- **本地反推服务**（后台运行，无窗口）：真正干活的部分，调用本机的 Claude 出结果。

四档反推：
| 档位 | 输出 |
|---|---|
| 纯服装（默认） | 只描述衣服，不写人物长相/场景 |
| 全要素 | 人物 + 服装 + 场景 + 光影 |
| 幽灵模特 | 全身无头透明身体 + 服装 |
| 反推全图 | 不套任何模板，自然描述整张图（人物+服装+场景+光影+氛围），入库单独归到「全图」类 |

提示词可切换 **英文 / 纯中文** 输出（默认中文）。支持**批量选多张图**，批量反推、批量复制/清除提示词。

## 二、开始前，你的电脑需要具备（前置条件）

> ⚠️ 这一步最关键。少了任何一项，插件都会「反推失败」。装之前先对照检查。

1. **Chrome 浏览器**（或 Edge 等 Chromium 内核浏览器）
2. **Node.js**（版本 18 或更高）
   - 检查方法：按 `Win + R` → 输入 `cmd` → 回车，在黑框里输入 `node --version` 回车
   - 显示 `v18.x` 或更高 = OK；提示「不是内部命令」= 没装，去 https://nodejs.org 下载 LTS 版安装
3. **Claude Code CLI**（本插件的反推引擎，需已登录/配置好额度）
   - 检查方法：`cmd` 里输入 `claude --version`
   - 显示版本号（如 `2.1.131`）= OK；报错 = 需先安装并登录 Claude Code
   - > 这一项是团队统一提供的账号/额度，若你不清楚如何配置，问 IT 或项目负责人拿好登录方式。

**三项都通过了，再往下走。**

## 三、安装步骤（第一次使用，约 3 分钟）

### 第 1 步：拿到插件文件夹

从负责人处拿到整个项目文件夹（或 Git 仓库），找到这个目录：

```
...\outputs\extension\        ← 浏览器扩展
...\outputs\server\           ← 本地反推服务
```

放到一个**路径固定、不会随便挪动**的地方（比如 `D:\服装资产库插件\`）。装好后别再移动，否则开机自启会失效。

### 第 2 步：装浏览器扩展

1. 打开 Chrome，地址栏输入 `chrome://extensions/` 回车
2. 打开右上角的 **「开发者模式」** 开关
3. 点左上角 **「加载已解压的扩展程序」**
4. 选中上面的 **`outputs\extension\`** 文件夹（注意是 extension 这一层，里面要能看到 `manifest.json`）
5. 扩展列表里出现 **「服装资产库 · 反推助手」** = 成功
6. 建议点扩展栏的拼图图标，把它 **📌 固定** 到工具栏

### 第 3 步：开启本地反推服务（开机自启，一劳永逸）

进入 **`outputs\server\scripts\`** 文件夹，**双击运行**：

```
install-autostart.bat
```

它会做两件事：
- 把服务注册进 Windows 开机启动（以后每次开机自动在后台运行，**无黑框、无感知**）
- 当场先启动一次（装完立刻就能用，不必等重启）

> 如果弹出安全提示，选择「仍要运行」即可（这是我们自己的脚本，不联网上传任何东西，只在本机 `127.0.0.1` 运行）。

**装好了！** 现在打开任意网页就能用。

## 四、日常怎么用

### 方式 A：悬浮按钮（推荐）
网页右侧会有一个**紫色衣架悬浮按钮**：
- **点它** → 唤起侧边栏
- 可以**上下拖动**它、松手会**吸到屏幕边缘**，位置会被记住

### 方式 B：鼠标悬停图片
鼠标移到网页里任意图片上（够大的图），角上会冒出 **「👕 反推服装」** 小框——点一下，该图**直接送入侧边栏并自动打开**。

### 方式 C：快捷键
按 **`Alt + Shift + S`** 唤起侧边栏。
> 若无反应，多半是快捷键被别的扩展占了：打开 `chrome://extensions/shortcuts` 改个组合即可。

### 侧边栏里能做什么
1. 选好 **反推档位**（纯服装 / 全要素 / 幽灵模特 / 反推全图）
2. 中文提示词**默认已开**；不需要可取消 **「输出纯中文提示词」**
3. 点 **反推** → 等几十秒出结果（本地 CLI 引擎速度取决于机器，一般 20~60 秒）
4. 反推完可 **复制提示词 / 清除提示词**
5. 满意就 **保存到资产库**，可顺手 **打标签**

### 批量反推（多图）
- 点侧边栏 **「批量选图」** → 到网页依次点要选的图（绿框计数），或直接鼠标悬停图片点 **「+ 加入批量」** 连续多选
- 回侧边栏，每张图一张卡片（缩略图 + 独立提示词框 + 标签）
- 选好档位点 **「一键反推」**（所有卡片按当前档位跑），可调**并发数**（本地 CLI 建议 ≤3）
- 顶部 **「一键复制提示词 / 一键清除提示词」** 批量操作，**「全部保存」** 一次入库

### 资产库
侧边栏里点进 **资产库**：
- 顶部切换 **「服装 / 全图」** 两大视图（全图档单独归类）
- 网格预览所有保存的图 + 提示词
- **一键复制**提示词 / 提示词+图片
- 点开图可在详情里 **增删标签**
- 左侧 **标签筛选（Eagle 式）**：点一次=包含(蓝)、再点=排除(红划线)、三点=取消；多标签可叠加，右上 **「清除标签筛选」** 重置

## 五、常见问题（重要，先看这里再找人）

**Q1：点反推提示「反推失败」？**
90% 是本地服务没在跑。
- 检查侧边栏顶部有没有 **橙色横条**「本地反推服务未启动」→ 点横条上的 **「重试连接」**
- 还不行：进 `outputs\server\scripts\` 重新双击 `install-autostart.bat`
- 确认前置条件里的 `claude --version` 能正常显示

**Q2：反推很慢？**
本地 CLI 引擎第一次冷启动较慢属正常，一般 20~60 秒。已默认用较快的模型。别重复点，耐心等计时结束。

**Q3：开机后忘了服务在不在跑？**
装了自启动就不用管，开机会自动后台运行。想手动确认：浏览器地址栏访问 `http://127.0.0.1:8787/health`，看到 `{"ok":true}` = 服务正常。

**Q4：某些图片反推不了？**
个别网站的图有防盗链或跨域限制取不到像素。换用**悬浮按钮**或右键图片走「反推此服装」通常能兜底。

**Q5：不想要开机自启了？**
双击 `outputs\server\scripts\uninstall-autostart.bat` 即可移除。

**Q6：换了电脑 / 挪了文件夹后失效？**
自启动记录的是旧路径。重新双击一次 `install-autostart.bat` 即可。

## 六、一句话给同事的极简版

> 1. 确认电脑装了 Node 和 Claude Code CLI（`cmd` 里 `node -v` 和 `claude --version` 都有版本号）

> 3. 双击 `outputs\server\scripts\install-autostart.bat`
> 4. 打开网页，点右侧紫色衣架按钮开干
